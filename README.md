
🚀 Telegram Ads Manager

A modular Telegram bot for creating and managing advertising campaigns directly from Telegram.

✨ Features

- 📢 Create advertising campaigns
- 📊 View and manage your campaigns
- 💰 Wallet and transaction tracking
- 📈 Campaign and platform statistics
- 👑 Owner/Admin panel
- 🔐 Force-join channel protection
- 💾 JSON-based data storage
- ⚙️ Environment-based configuration
- 🧩 Modular handlers and services
- 🚀 Ready for cloud deployment

📁 Structure

telegram-ads-manager/
├── bot.js
├── package.json
├── .env
├── config/
├── database/
├── handlers/
├── services/
└── data/

🛠️ Installation

git clone YOUR_REPOSITORY_URL
cd telegram-ads-manager
npm install

Create ".env" and configure your Telegram BotFather token, owner ID, bot information, and Force Join channels.

▶️ Start

npm start

⚠️ Security

Never publish your ".env" file or expose your Telegram bot token. Add ".env" to ".gitignore".
